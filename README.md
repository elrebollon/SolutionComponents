# Solution Component Inspector for XrmToolBox

[![GitHub Sponsors](https://img.shields.io/badge/sponsor-GitHub%20Sponsors-ea4aaa?logo=github)](https://github.com/sponsors/elrebollon)
[![Release](https://img.shields.io/badge/release-v1.0.0-blue.svg)](https://github.com/elrebollon/SolutionComponents/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A powerful **XrmToolBox** plugin designed to inspect solution component dependencies, identify cross-solution overlaps, and track component history across Microsoft Dynamics 365 and Microsoft Dataverse environments.

---

## Key Features

- **Solution Overlap Audit**: Select any unmanaged or managed solution to inspect all its components and see in real time which other solutions share those same components.
- **Component History & Hierarchy Tracking**: Search and trace individual components (Entities, Fields, Relationships, Forms, Views, Workflows, Cloud Flows, Plugins, Canvas Apps, etc.) across all historical solution versions.
- **Publisher Filtering**: Exclude Microsoft or third-party publishers from audit results to focus exclusively on your custom solutions.
- **Responsive & Asynchronous**: All Dataverse queries execute asynchronously in the background via `WorkAsync`, ensuring the UI never freezes.
- **Native XrmToolBox Integration**: Fully compliant with XrmToolBox standard interfaces for GitHub issues, documentation, and metadata.

---

## Installation

1. Open **XrmToolBox**.
2. Go to **Configuration** > **Tool Library**.
3. Search for **Solution Component Inspector**.
4. Click **Install**.
